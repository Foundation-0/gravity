# Persistence probe

These calculations test selected mathematical conditions for persistent patterns. They use ideal models and supply no measured persistence or astrophysical validation.

Run from the repository root:

```sh
python3 research/convergences-20261112/probes/persistence/persistence_probes.py
```

This rewrites `results.json` beside the script. Use the bundle command `python3 research/convergences-20261112/check.py` to regenerate in a temporary directory and verify all saved numerical results.
