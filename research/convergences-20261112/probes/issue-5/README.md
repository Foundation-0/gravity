# Issue-5 probe

These analytic and symbolic checks examine the proposed AeST interpretation in issue #5. They do not simulate collapse or establish the model's physical viability.

Run from the repository root:

```sh
python3 research/convergences-20261112/probes/issue-5/issue5_checks.py
```

This rewrites `results.json` beside the script. Use the bundle command `python3 research/convergences-20261112/check.py` to regenerate in a temporary directory and verify all saved numerical results.
